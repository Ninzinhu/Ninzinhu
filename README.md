## 👾 / sobre mim

Sou **João Victor Emmanuell**, também conhecido como **Ninzinhu**, estudante de **Sistemas de Informação na [Estácio](https://estacio.br/cursos/graduacao)**.

Gosto de entender o que acontece além da interface: como o código se organiza, como os sistemas se comunicam e onde a segurança entra em cada decisão. Meu foco reúne **desenvolvimento, cloud e cibersegurança**, com espaço para experimentar e aprender construindo.

- **Construir:** aplicações, plugins e integrações — incluindo projetos em Java para jogos.
- **Entender:** arquitetura, APIs, infraestrutura e o caminho dos dados entre sistemas.
- **Proteger:** explorar segurança de aplicações e práticas de desenvolvimento seguro.
- **Desconectar:** academia, cultura japonesa e idioma japonês.
